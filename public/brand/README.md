# Brand assets

Drop the official emblem here as **`emblem.png`** (transparent PNG, ideally
~120px tall or larger) and it will appear automatically in the app header.

    public/brand/emblem.png

Until a file exists here, the app shows a custom "26" fallback mark instead of
the trademarked logo. SVG also works — if you prefer SVG, save it as
`emblem.png`-named export, or tell me and I'll switch the path in
`src/components/BrandMark.tsx`.

Note: the official FIFA World Cup 26™ emblem is trademarked. Only use it if your
use case is licensed/permitted.
